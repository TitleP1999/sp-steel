# SUPARERK STEEL V9

V9 adds a homepage Facebook News & Updates section after OUR BRANDS.

- SUPARERK STEEL Suphanburi: https://www.facebook.com/SuparerkSteelSuphanburi
- SUPARERK STEEL Kanchanaburi: https://www.facebook.com/SuparerkSteelKanchanaburi
